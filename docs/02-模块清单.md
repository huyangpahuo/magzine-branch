# 02 模块清单

> 逐文件对照表。原则:**单个脚本只负责单个功能**。除桌宠模块族(ES Module
> 内部 import)外,模块之间不互相调用,只通过 `window.theme`、`window.i18n`、
> `window.HeroFX`、`window.__magzinePjax` 等少量全局约定协作(见
> [01-架构总览](01-架构总览.md) 第六节)。

## 一、布局模板(layout/,24 个)

### 骨架与入口

| 文件 | 职责 |
|---|---|
| `layout.pug` | 总骨架。`<head>` 内联暗色预置/iframe 标记/读者设置覆盖样式;全局加载全部 CSS;按顺序 `defer` 加载全部脚本;注入 `window.theme` 配置与 `inject.head/bottom`;挂载特效层与桌宠、Sakana、音乐播放器、封面等常驻组件 |
| `page.pug` | 独立页(不含目录/分享/AI 摘要) |
| `404.pug` | 404 页,含站内导航兜底 |

### 页面

| 文件 | 职责 |
|---|---|
| `index.pug` | 首页:Hero 区(背景图/打字机/特效层/特效面板挂载点)+ 作者卡片 + 文章卡片列表 + "加载更多"分页器 |
| `post.pug` | 文章页:封面、元信息(分类/日期/作者/字数/阅读时长)、目录侧栏、正文、AI 摘要容器、上下篇、分享、相关文章、评论区;并向父窗口 `postMessage` 上报标题(供模态窗口使用),同时输出 `data-post-page` 供 just-read 识别 |
| `archive.pug` | 归档页:按年分组的时间轴,日期带 `data-date-standard` 供翻译层换算格式 |
| `categories.pug` | 分类页:竖排手风琴 + 文件夹视图(两套结构共存,由 class 切换) |
| `category.pug` / `tag.pug` | 单个分类/标签的文章列表页 |
| `about.pug` | 关于页:头像与简介、兴趣卡片(数据来自 `_data/about.yml`)、个人信息、技能标签云、碎碎念正文、联系方式 |
| `link.pug` | 友链页:链接卡片网格 + 添加友链说明与复制模板 + 评论区 |
| `anime.pug` | 追番页:番剧卡片网格(每张卡片内嵌 sources/episodes 数据)、播放器模态窗口、选集侧栏、换源下拉、角色菜单容器 |

| `murmur.pug` | 万花筒(碎碎念):横幅 + 瀑布流卡片,支持视频门面播放 |

## 二、构建期脚本(scripts/,21 个)

> Hexo 启动时自动加载 `themes/<theme>/scripts/**/*.js`。这些脚本运行在 Node 侧,
> 用 `hexo.extend.*` 注册生成器/过滤器/助手/标签。

### 过滤器与生成器

| 文件 | 职责 |
|---|---|
| `filters/highlight.js` | **代码块结构重写**:把 Hexo 默认的 `figure.highlight > table` 转成 `.codecard`(header + 行号 gutter + pre),为深浅自适应卡片、语言标签、复制/折叠按钮提供结构 |
| `other/lang-dict.js` | **多语言字典生成器**:读取 `language/*.yml`,把"基准语言中文原文 → 各语言译文"拉链成 `public/js/core/lang-dict.js`,同时输出语言元信息(flag/label);缺键与同中文冲突会打警告 |
| `other/i18n-attrs.js` | **注册 `i18n_attrs(obj, field[, attr])` Pug 助手**:按 `language/` 目录里实际存在的语言,把数据对象的 `field_en`/`field_ja`/… 自动展开成 `data-i18n-*` 属性。新增语言无需改模板 |
| `other/compress-images.js` | **路由流图片压缩/WebP**:包装图片路由用 sharp 压缩,包装文本路由自动把引用改写成 `.webp`;带 400MB FIFO 转换缓存与 `protect` 保护名单 |
| `other/lazy-images.js` | `after_render:html` 给所有 `<img>` 补 `loading="lazy"`(已在 HTML 里写死,浏览器解析即生效,无需等 JS) |
| `other/merge-categories.js` | 合并大小写/空格差异造成的重复分类(如 `hexo` 与 `Hexo`),供分类页调用 `merged_categories()` |
| `other/murmur-video.js` | 万花筒页视频解析:把视频 URL 转成"点击加载门面",避免第三方播放器自动播放 |
| `other/bilibili-meta.js` | B 站视频元信息抓取(封面/时长) |
| `other/notfound-html.js` | 404 页处理与输出 |
| `other/nunjucks-regex-token-fix.js` | 模板正则 token 修复(Hexo 渲染器边界情况兜底) |

## 三、运行期脚本(source/js/,54 个)

目录按职能分组。下表"触发时机"指该模块何时生效。

### 3.1 core/ — 页面骨架与全局机制(9 个)

| 文件 | 职责 | 触发时机 |
|---|---|---|
| `main.js` | 通用初始化集合:首页打字机(文本按当前语言取词)、返回顶部、暗色切换按钮、平滑滚动、代码块旧结构折叠兜底、作者卡片拉绳动画 | 每页 |
| `lang-switch.js` | **多语言运行时**:读 `window.__MAGZINE_LANG_DICTS__`,按当前语言翻译整页;处理 `data-i18n-*` 显式属性、字典兜底、英文回退;翻译日期格式;语言按钮循环切换;广播 `langchange`;暴露 `window.i18n`(`get`/`format`/`lang`/`langs`/`applyLanguage`) | 每页 |
| `pjax-init.js` | **无感刷新**:白名单内页面点击不整页跳转,只换 `main.main` 与 `<title>`,保留导航/播放器/桌宠/封面;换页后重放内嵌脚本、重派发 `DOMContentLoaded`、派发 `pjax:send|complete`;暴露 `window.__magzinePjax.load` | 每页(可关) |
| `reader-settings.js` | **读者设置面板**:在 `<head>` 尽早执行,把浏览器里保存的读者设置应用为覆盖样式与配置补丁(防闪烁);桌面端右键页面空白处弹面板(跳过自带右键菜单的元素与桌宠,见 `data-own-context-menu`);"确定设置"保存并整页刷新 | `<head>` + 每页 |
| `load-more.js` | 首页"加载更多":页码可编辑的翻页器、追加下一页卡片、按链接去重、随机大小排版、按钮文案按语言切换 | 首页 |

| `dark-mode-sync.js` | 暗色模式跨页同步(含 pjax 与 iframe 场景),避免明暗跳变 | 每页 |
| `header-scroll.js` | 顶栏滚动隐藏/显示,并切换顶栏样式 | 每页 |
| `loading-animation.js` | 首屏加载动画与就绪后的淡出 | 每页 |
