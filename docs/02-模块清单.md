# 02 模块清单

> 原则:**单个脚本只负责单个功能**。除 `main.js`(页面通用初始化)外,
> 每个文件都是一个自足的功能模块,相互之间不直接调用(仅通过
> `window.theme` 配置、`window.openImageViewer` 等少量全局约定协作)。

## 一、布局(layout/)

| 文件 | 功能 |
|---|---|
| `layout.pug` | 总骨架:head 资源加载(全部 defer)、特效挂载点、`window.theme` 配置注入 |
| `index.pug` | 首页 hero + 文章卡片列表 |
| `post.pug` / `page.pug` | 文章页/独立页(`data-post-page` 标记供 just-read.js 识别) |
| `archive/category/tag/categories.pug` | 归档/分类/标签页 |
| `about/link/anime/wall/murmur.pug` | 关于/友链/追番/照片墙/碎碎念独立页 |
| `404.pug` | 404 页 |
| `_partial/header.pug` | 导航栏(bubble/fill 两种样式) |
| `_partial/cover.pug` | 启动封面:WebGL 液体背景(本地 liquid1 模块,第二实例延迟创建)+ 打字动画 |
| `_partial/pet.pug` | 桌宠:HTML/CSS/主循环(module 脚本),import `js/pet/*` 模块族 |
| `_partial/sakana.pug` | Sakana 小人(本地图片 + 物理引擎 sakana.min.js,已调温和) |
| `_partial/music-player.pug` | 悬浮音乐播放器(数据来自 `_data/music.yml`) |
| `_partial/comments.pug` | 评论区(twikoo 本地脚本 + 滚动到附近才加载) |
| `_partial/search.pug` / `color-picker.pug` / `footer.pug` / `author-card.pug` | 搜索/调色盘/页脚/作者卡片 |

## 三、运行时脚本(source/js/)

目录按职能分组(与 pet/ 同样的组织方式):

```
js/
├── core/      页面骨架与全局机制
├── content/   文章内容渲染
├── effects/   视觉特效
├── features/  站点功能组件
├── pages/     独立页面脚本
├── pet/       桌宠模块族(ES module)
└── vendor/    本地化第三方库
```

### core 页面骨架

| 文件 | 功能 |
|---|---|
| `core/main.js` | 通用初始化集合:打字机、代码块旧结构折叠兜底、作者卡片动画等 |
| `content/content-lazy.js` | **按视口加载核心**:content-visibility(iframe/video/公式/视频壳)、懒加载补齐、视频离屏暂停、阅读显现动画 |
| `content/highlight.js` | 代码块 v2 交互:复制、折叠、滚轮横滑 |
| `content/toc.js` | 目录:嵌套可折叠树、滚动高亮自动展开路径 |
| `content/table.js` | 表格:横向滚动、行数折叠、全屏查看器(含惯性拖拽) |
| `content/mermaid.js` | mermaid 按视口渲染 + 全屏查看器(含惯性拖拽) |
| `content/image-zoom.js` | 图片查看器:1:1 拖拽切换/甩动判定/平移惯性/缩略图胶片条 |
| `content/math-support.js` | 公式:仅含公式页加载 MathJax(空闲时) |
| `core/lang-switch.js` | 中英切换(翻译字典 + `window.i18n.get`) |

## 四、样式(source/css/)

命名即功能:`main.css`(全局+布局)、每页面一份(`about/wall/anime/link/murmur/404.css`,
以页面级 class 作用域)、每组件一份(`codecard 在 highlight.css`、`image-zoom/toc/table/mermaid/
search/share/music-player/article-modal/mobile-nav/scrollbar/timeline/tags/carrier…
css`)、`cursor.css`(阿尼亚光标帧)。

**为什么全部页面 CSS 全局加载**:pjax 只替换 `main.main` 不换 `<head>`,
样式必须常驻;页面级 CSS 均有页面 class 作用域,不会互相污染。
