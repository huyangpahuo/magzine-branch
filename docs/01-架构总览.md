# 01 架构总览

## 一、构建期流水线

```mermaid
flowchart TD
    A["hexo generate 或 hexo server"] --> B["Hexo 加载"]
    B --> C["主题 scripts 构建脚本"]
    C --> C1["highlight.js 代码块结构转换"]
    C --> C2["lazy-images.js 补图片懒加载属性"]
    C --> C3["compress-images.js 路由流图片压缩与WebP"]
    C --> C4["merge-categories 等数据整理"]
    B --> D["渲染页面 pug 布局"]
    D --> E["after_render 过滤器"]
    C --> F["路由 route 流"]
    E --> F
    F --> G{"输出方式"}
    G -->|写盘| H["public 静态文件"]
    G -->|server| I["本地预览响应"]
    H --> J["GitHub Actions 发布"]
```

关键设计:压缩与转换发生在路由流上,而不是扫描 public 文件夹,因此一次
`hexo generate` 即完成,`hexo server` 预览看到的也是压缩后效果。

## 二、页面运行时组件

```mermaid
flowchart LR
    subgraph SG1["页面骨架 layout.pug"]
        HEADER["header 导航"]
        MAIN["main 主内容"]
        FOOTER["footer 波浪"]
    end

    subgraph SG2["常驻特效 按层级从低到高"]
        LEAVES["落叶 canvas 层级999"]
        MODAL["文章模态 iframe 层级1000"]
        PET["桌宠 层级2000"]
        VIEWERS["三个全屏查看器 层级9999以上"]
    end

    subgraph SG3["按需加载 滚到附近才启动"]
        TWIKOO["评论区"]
        MERMAID["mermaid 库与渲染"]
        MATHJAX["MathJax 仅公式页"]
    end

    MAIN --> SG2
    MAIN --> SG3
```

层级规则:落叶在模态背后;桌宠在模态之上、全屏查看器之下;模态 iframe
内打开全屏查看器时,通过 postMessage 通知父页面把桌宠临时沉底并静音粒子。

## 三、文章浏览的两种模式

```mermaid
sequenceDiagram
    participant U as 读者
    participant H as 首页
    participant M as 模态iframe
    U->>H: 点击文章卡片
    alt 模态模式(默认)
        H->>M: iframe 加载文章页
        M->>M: 桌宠文字避让只包裹视口附近段落
        U->>M: 滚动到底部
        M->>M: 评论区进入范围才加载 twikoo
    else 直链模式
        H->>H: 整页跳转
    end
```

## 四、脚本加载策略

- 全站脚本使用 defer,不阻塞 HTML 解析,保持文档顺序执行,且都在
  DOMContentLoaded 之前跑完;
- pjax 换页后由 pjax-init 重新派发 DOMContentLoaded 唤醒各模块,模块内部
  用幂等标记防重入;
- 三类重资源按视口触发:评论(600px 范围)、mermaid(正负 1.5 屏才下载库
  并渲染)、MathJax(正文含公式才加载且等浏览器空闲)。

## 五、特效层级总表

| 组件 | z-index | 说明 |
|---|---|---|
| 落叶 canvas | 999 | 正文之上,模态与查看器之下 |
| 文章模态 | 1000 | 全屏 iframe |
| 桌宠(含影子光环气泡) | 2000 | 模态之上,要在模态里跑动 |
| 桌宠烟雾粒子 | 2001 | 查看器打开时静音不生成 |
| 桌宠右键菜单 | 2001 | 与桌宠同族 |
| 图片表格mermaid查看器 | 9999~10020 | 最高层,打开时联动桌宠沉底 |
