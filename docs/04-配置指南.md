# 04 配置指南

> 全部配置在 `themes/magzine/_config.yml`。读者个人设置(右键面板)
> 保存在浏览器 `localStorage`,可在主题配置基础上被读者覆盖。

## 一、站点标识

| 配置 | 说明 |
|---|---|
| `favicon` | 站点图标 |
| `logo` | 导航栏左侧图标 |
| `menu` | 导航菜单。一级项为 `名称: 路径`;值为对象则生成下拉子菜单;`"#lang-switch"` 是语言切换按钮的占位 |
| `social` | 社交链接(github / email / bilibili) |
| `navbar.style` | 顶栏样式:`bubble` 气泡式 / `fill` 填充式 |
| `footer.*` | 页脚版权、自定义 HTML、可选图片链接 |

## 二、首页与封面

| 配置 | 说明 |
|---|---|
| `hero.enable` | 首页大图区开关 |
| `hero.background_image` | 首页背景图(首屏 LCP,保持 eager 加载) |
| `hero.typing_text` / `typing_speed` / `delete_speed` / `pause_duration` | 打字机文案与节奏。文案写中文即可,运行期按当前语言查表 |
| `hero.scroll_hint` | 向下滚动提示文案 |
| `cover.enable` | 开屏封面(WebGL 液体折射背景) |
| `cover.title` / `author` / `btn_text` | 封面标题、副标题、按钮文案 |
| `cover.images` | 封面轮播图列表(按顺序播放,至少两张) |
| `author_card.*` | 作者名片:头像、名称、简介、按钮、背景图、宽度档位、背景几何动画 |

## 三、首页特效(可扩展框架)

| 配置 | 说明 |
|---|---|
| `hero.effects.enable` | 特效总开关 |
| `hero.effects.panel_enable` | 是否显示特效控制面板(`✦ 特效` 按钮) |
| `hero.effects.mobile_enable` | 是否在手机移动端启用首页特效,**默认 false**(WebGL 渲染较重,出于性能考虑默认关闭;开启后移动端同样可用面板) |
| `hero.effects.fluid.*` | 流体模拟:`enable` `color_source`(image/random) `quality`(high/medium/low) `curl` `splat_radius` `density_dissipation` `velocity_dissipation` `hover` `hold_on_hover` `idle_splat` `bloom` |
| `hero.effects.fluid.hold_on_hover` | 指针停在 hero 上时流体不消散(离开 hero 后才平滑淡出),默认 true |
| `hero.effects.watercolor.*` | 水彩光晕:`enable` `speed` `intensity` `hover` |

两种特效可同时存在,面板内互斥启用(同时最多开一个,避免双重 canvas 开销)。
读者在面板上的改动写入 `localStorage`,优先于这里的默认值。
扩展方式见 [07-首页特效框架](07-首页特效框架.md)。

## 四、文章与列表

| 配置 | 说明 |
|---|---|
| `article_list.card_size` | 卡片尺寸档位:`normal` / `large` |
| `article_list.view_mode` | 浏览方式:`modal`(iframe 模态窗口)/ `redirect`(整页跳转) |
| `theme_config.post.excerpt_length` | 摘要截取字数 |
| `theme_config.post.use_default_cover` / `default_cover` | 无封面文章使用默认封面 |
| `wordcount.enable` | 字数统计与阅读时长(需 `hexo-wordcount`) |
| `toc.empty_toc_behavior` | 无目录时 `placeholder` 占位 / `hide` 隐藏侧栏 |
| `just_read.enable` | "刚读过"文章置顶并挂徽章 |
| `code_block.height_limit` / `enable_folding` / `max_height` / `show_lang` | 代码块折叠阈值、最大高度、语言标签 |

## 五、分类与标签页

| 配置 | 说明 |
|---|---|
| `categories.layout` | `accordion` 展开式 / `page` 跳转式 |
| `categories.accordion_animation` | 展开折叠动画 |
| `categories.show_empty_categories` | 是否显示没有文章的分类 |
| `categories.explorer` | 桌面端"文件夹"视图(可在页面上与竖排互相切换) |

## 六、图片查看器

| 配置 | 说明 |
|---|---|
| `image_viewer.desktop_thumbnails` | 桌面端缩略图胶片条 |
| `image_viewer.mobile_thumbnails` | 移动端缩略图 |
| `image_viewer.desktop_switch_mode` | 桌面端切换方式:`peek`(两侧预览图,点击切换)/ `buttons`(上下张按钮) |

## 七、组件开关

| 配置 | 默认 | 说明 |
|---|---|---|
| `pet.enable` | true | 桌宠。`mobile_enable` 控制移动端;`pretext_interaction.*` 是文字避让(半径/节流/作用选择器) |
| `sakana.enable` | true | Sakana 悬挂小人 |
| `color_picker.enable` | true | 右上角调色盘 |
| `music_player.*` | — | 悬浮播放器:`enable` `style`(pill/card) `pc_position`(header/float) `autoplay` `default_cover` `opacity`;曲目在站点 `source/_data/music.yml` |
| `cursor.enable` | true | 阿尼亚动态光标(帧资源在 `source/cursors/anya/`) |
| `pjax.enable` | true | 无感刷新 |
| `features.*` | 全开 | `dark_mode` `smooth_scroll` `back_to_top` `loading_animation` |
| `murmur.banner.*` | — | 万花筒页横幅背景图 |

## 八、读者设置面板

| 配置 | 说明 |
|---|---|
| `reader_settings.enable` | 是否启用右键设置面板 |
| `reader_settings.items.*` | 每个开关是否对读者可见:`music_player` `pet` `sakana` `navbar` `theme_color` `click_effect` `cover` `hero` `article_view` `pjax` `murmur_banner` `author_card` `image_viewer` `falling_leaves` |

读者在面板里的选择存浏览器,并会覆盖上表对应的主题配置(实现方式见
`core/reader-settings.js`:在 `<head>` 尽早应用覆盖样式防闪烁)。

## 九、评论与分享

| 配置 | 说明 |
|---|---|
| `comments.enable` / `comments.type` | 启用与类型(`twikoo` / `disqus` / `gitalk` / `valine`) |
| `comments.twikoo.envId` `region` `visitor` | twikoo 后端地址与配置(建议部署在境内,滚到评论区附近才加载) |
| `share.enable` / `share.options.*` | 分享按钮:twitter / facebook / linkedin / copy_link / wechat / qq / weibo |

## 十、AI 摘要

| 配置 | 说明 |
|---|---|
| `ai_summary.enable` | 总开关 |
| `ai_summary.summary_directly` | 是否进入文章即自动生成摘要(否则等读者点按钮) |
| `ai_summary.ai_name` / `ai_introduce` / `ai_version` | 面板标题、自我介绍、版本标签 |
| `ai_summary.buttons` | 三个按钮文案(运行期按当前语言查表) |
| `ai_summary.api_key` | 接口密钥(留空则用内置代理地址;教程见 README) |

**AI 的回复语言跟随界面语言**:提示词写在 `language/*.yml` 的 `ai.prompt_*` 里,
每个语言一份,详见 [06-国际化架构](06-国际化架构.md)。

## 十一、追番页

| 配置 | 说明 |
|---|---|
| `anime.player_api` | 默认播放接口(B 站解析) |
| `anime.history` | 是否记录观看历史(以中文原题为稳定键,已在卡片上打本地徽章) |

番剧数据在站点 `source/_data/anime/*.yml`,每部一个文件,字段见
[09-内容标签与数据文件](09-内容标签与数据文件.md)。

## 十二、多语言

| 位置 | 说明 |
|---|---|
| `themes/magzine/language/zh.yml` | 基准字典(键 + 中文原文) |
| `themes/magzine/language/<lang>.yml` | 各语言译文,顶层 `_meta` 提供按钮 `flag`/`label` |
| `themes/magzine/language/translations-backup.js` | 早期方案的备份,不参与构建 |

新增语言只需在 `language/` 放一份 yml,不需要改 `_config.yml`、模板或 JS。
详见 [06-国际化架构](06-国际化架构.md)。

## 十三、资源与性能

| 配置 | 说明 |
|---|---|
| `compress_images.*` | 图片压缩/WebP:`enable` `mode` `max_width` `min_size` `ignore` `protect` `quality.*`(详见 [03-构建与部署](03-构建与部署.md)) |
| `theme_config.performance.*` | `lazyload` / `minify` / `cache` |
| `theme_config.search.*` | 站内搜索(本地索引;亦留了 Algolia 字段) |
| `theme_config.analytics.*` | Google / 百度统计开关与 ID |
| `inject.head` / `inject.bottom` | 追加自定义 `<link>`/`<script>`(脚本自动补 `defer`) |
| `CDN.internal_provider` / `third_party_provider` | 主题内部资源与第三方资源来源(默认 local + unpkg) |

## 十四、资源目录约定

| 目录 | 内容 |
|---|---|
| `source/images/` | 站点级图片(封面轮播、头像、默认封面等,构建期自动转 WebP) |
| `source/images/pet/` | 桌宠精灵图(**protect 保护**,不改名) |
| `source/cursors/anya/` | 光标帧(**protect 保护**) |
| `source/images/sakana/` | Sakana 立绘(本地化) |
| `source/lib/` | 本地化第三方库(目前:Font Awesome) |
| `source/js/vendor/` | 本地化第三方 JS(twikoo / liquid) |
| 站点 `source/_data/` | 页面数据(music / link / about / anime / murmur) |
