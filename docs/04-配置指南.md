# 04 配置指南(主题 _config.yml)

> 所有配置都在 `themes/magzine/_config.yml`。读者个人设置(右键面板)
> 存浏览器 localStorage,可在主题配置基础上覆盖。

## 视觉

| 配置 | 说明 |
|---|---|
| `hero.*` | 首页大图、打字机文案与速度 |
| `cover.*` | 启动封面:标题/按钮/轮播图列表(本地 liquid WebGL) |
| `colors.*` / `color_picker` | 主题色体系与右上角调色盘 |
| `fonts.*` | 字体栈定义(Inter 等已回退系统字体;Google Fonts 已移除) |
| `navbar.style` | `bubble` 气泡式 / `fill` 填充式 |
| `author_card.*` | 作者卡片(头像/简介/背景图/背景动画) |
| `murmur.banner` | 碎碎念页横幅背景图 |
| `footer.*` | 页脚文案/图片/链接 |

## 功能开关

| 配置 | 默认 | 说明 |
|---|---|---|
| `pet.enable` | true | 桌宠(含文字避让 `pretext_interaction.*`:半径/节流/白名单选择器) |
| `sakana.enable` | true | Sakana 小人 |
| `music_player.*` | 启用 | 悬浮播放器(曲目在 `source/_data/music.yml`) |
| `click 效果` | 经 inject | 爱心/烟花二选一+关闭,读者面板可切 |
| `falling_leaves` | 经 inject | 落叶特效(读者面板可关) |
| `cursor.enable` | true | 阿尼亚动态光标(帧资源在 `cursors/anya/`) |
| `pjax.enable` | true | 无感刷新 |
| `just_read` | true | "刚读过"置顶卡片 |
| `reader_settings.*` | 全开 | 右键设置面板各开关是否对读者可见 |
| `article_list.view_mode` | modal | 文章浏览:`modal` 模态 / `redirect` 直链 |
| `image_viewer.*` | — | 图片查看器:缩略图开关、切换模式(peek/buttons) |
| `code_block.*` | — | 代码块:高度限制/折叠/语言标签 |
| `toc.empty_toc_behavior` | placeholder | 无目录时隐藏侧栏或占位 |
| `categories.*` | — | 分类页样式(展开式/文件夹视图) |
| `comments.*` | twikoo | 评论:类型与 envId(建议部署在境内) |
| `ai_summary.*` | — | AI 摘要(阿罗娜) |
| `search` / `feed` / `mermaid` | — | 站点级 _config.yml 对应插件配置 |

## 资源与性能

| 配置 | 说明 |
|---|---|
| `compress_images.*` | 图片压缩/WebP(详见 [03-构建与部署](03-构建与部署.md)) |
| `inject.head/bottom` | 自定义 CSS/JS 注入(脚本会自动加 defer) |
| `CDN.internal_provider` | 主题内部资源来源(保持 local) |

## 资源目录约定

| 目录 | 内容 |
|---|---|
| `source/images/` | 站点级图片(封面轮播、头像、默认封面等,构建期自动转 WebP) |
| `source/images/pet/` | 桌宠精灵图(**protect 保护**,不改名) |
| `source/cursors/anya/` | 光标帧(**protect 保护**) |
| `source/images/sakana/` | Sakana 立绘(本地化) |
| `source/lib/` | 本地化第三方库(目前:Font Awesome) |
| `source/js/vendor/` | 本地化第三方 JS(twikoo / liquid1) |
| `source/_data/` | 页面数据(music/link/about/anime/murmur) |
