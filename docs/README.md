## 快速上手

```bash
# 1. 主题放进 themes/
git clone https://github.com/huyangpahuo/magzine-branch.git themes/magzine

# 2. 站点 _config.yml
theme: magzine

# 3. 安装依赖
npm install
```

其余能力(图片压缩/WebP、按视口渲染、首页特效、多语言、桌宠)默认开启,
逐项可在 [04-配置指南](04-配置指南.md) 中调整。
