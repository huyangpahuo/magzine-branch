# 09 内容标签与数据文件

> 这篇文章里能用的标签,以及各页面数据文件的字段约定。

## 一、内容标签(scripts/tag/)

在 Markdown 文章里用 Hexo 标签语法调用。标签在**构建期**渲染成 HTML,交互由
`source/js/content/*` 或 `source/js/pages/*` 接管(全部支持 pjax 与模态窗口)。

### 按钮

```markdown
{% btn https://example.com 点我 fa fa-link %}
```

参数:`url` `text` `icon` `option`。`option` 可用:`color`(default/blue/pink/red/
purple/orange/green)、`outline`、`center`、`block`、`larger`。

### 图片

```markdown
{% image 图片地址, alt 文字, 宽度, 高度 %}
{% inlineimage 图片地址 %}
```

支持图注与对齐;正文图片由图片查看器接管(点击放大、拖拽切换、缩略图胶片条)。

### 轮播图

在文章里把多张图片以轮播形式展示,**每行一张图**:

```markdown
{% carousel %}
<img src="文章资源文件夹/1.png" alt="说明文字">
<img src="文章资源文件夹/2.png">
{% endcarousel %}
```

可选参数(空格分隔,顺序不限):

| 参数 | 默认 | 说明 |
|---|---|---|
| `interval=4000` | 4000 | 自动播放间隔(ms),`0` 关闭自动播放 |
| `height=480` | 480 | 轮播窗口高度(px),手机端按屏宽收缩 |
| `ratio=16:9` | — | 改用固定宽高比(设置后 `height` 失效) |
| `fit=contain` | contain | `contain` 等比不裁剪 / `cover` 裁剪铺满 |
| `dots=false` | true | 是否显示圆点指示器 |

除 `<img>` 与 Markdown 图片外,还会识别资源流水线改写出的 `{% asset_img %}` 行。

### 折叠面板

```markdown
{% folding 边框色, 标题 %}
内容(按 Markdown 渲染)
{% endfolding %}
```

### 提示块

```markdown
{% note info fa fa-info-circle %}
内容
{% endnote %}
{% subnote warning %}
子级提示
{% endsubnote %}
```

样式关键字:`flat` / `modern` / `simple` / `disabled`(缺省为 `simple`);
倒数第二个参数若以 `fa` 开头会被当作图标。

### 隐藏内容

```markdown
行内:{% hideInline 这是隐藏内容, 点我查看, #eee, #333 %}
块级:
{% hideToggle 标题, #eee, #333 %}
隐藏的整块内容(Markdown 渲染)
{% endhideToggle %}
```

`hideInline` 参数:`content, display, bgColor, textColor`。

### 标签徽章

```markdown
{% label 文字 颜色 %}
```

颜色可用 `primary` `success` `info` `warning` `danger` `important`,也可直接写色值。

### 选项卡

```markdown
{% tabs 分组id %}
<!-- tab 标签1 -->
内容1
<!-- tab 标签2 -->
内容2
{% endtabs %}
```

### 时间线

```markdown
{% timeline %}
{% timenode 2026-01-01 第一件事 %}
说明内容
{% endtimenode %}
{% endtimeline %}
```

### 视频

```markdown
{% video https://www.bilibili.com/video/BVxxxx %}
{% video 视频标题 https://www.bilibili.com/video/BVxxxx %}
```

支持哔哩哔哩 / AcFun / 虎牙 / 直链等。所有平台**都是点击加载门面**:默认只渲染
封面,点击后才插入 iframe,因此不会自动播放、不拖慢首屏;点开一个会自动收回其他
(等效暂停)。未收录的平台会回退为普通链接。

## 二、页面数据文件(site/source/_data/)

### `about.yml` — 关于页兴趣卡片

```yaml
cards:
  - title: "逃离后室"
    title_en: "Escape the Backrooms"     # 可选:显式译文(优先级最高)
    title_ja: "バックルームからの脱出"
    image: "/images/13.jpg"              # 或 background: 渐变
    link: "https://..."
    description: "一句话描述"
    description_en: "..."
    details: "悬停时显示的补充文字"
    details_en: "..."
    icon: "fas fa-heart"
    layout: "portrait"                   # portrait / landscape
    size: "large"                        # large / medium / small
```

未提供的语言字段会回退到字典(见 [06-国际化架构](06-国际化架构.md))。

### `link.yml` — 友链

```yaml
- name: 站点名
  link: https://站点地址
  avatar: https://头像地址
  description: 一句话介绍
  # 可选的显式译文:name_en / description_en / …(友链通常无需翻译站名)
```

页面会自动探测头像可用性与站点连通性并给出状态圆点。

### `anime/*.yml` — 追番(每部一个文件)

```yaml
- title: 间谍过家家第二季            # 中文原名(观看历史的稳定键)
  title_en: "SPY×FAMILY Season 2"   # 可选:显式译文
  title_ja: "SPY×FAMILY シーズン2"
  cover: https://封面图地址
  bangumi_url: "https://bangumi.tv/subject/411427"   # 用于拉取角色信息
  sources:                          # 播放源(可多个,面板可切换)
    - name: "BiliBili"
      player_api: ""
      episodes:
        - title: "1"
          url: "https://www.bilibili.com/bangumi/play/ep..."
```

文件名任意(目录会被扫描),支持两种写法:`sources` 数组,或直接在根上写
`url` / `episodes`(旧版写法,自动兼容)。

### `murmur.yml` — 万花筒(碎碎念)

条目列表,支持文本与视频;视频会被渲染成点击加载门面。

### `music.yml` — 音乐播放器曲目

```yaml
- name: 曲名
  artist: 艺术家
  url: 音频直链
  cover: 封面图
  lrc: 歌词(可选)
```

## 三、写作提示

| 事项 | 说明 |
|---|---|
| 文章摘要 | 正文里的 `<!-- more -->` 之前的内容;或由 `theme_config.post.excerpt_length` 截取 |
| 双语标题 | front-matter 写 `title_en:`(以及 `description_en`、`title_ja` …),模板会自动输出对应属性 |
| 图片 | 建议用 `post_asset_folder` + `{% image %}` 或 Markdown,构建期自动压缩/WebP |
| 表格 | 超过一定行数自动折叠,滚轮横向滚动,可全屏查看 |
| 代码块 | 构建期重写为卡片结构,支持语言标签、行号、复制、折叠 |
| 公式 | 正文出现 `$...$` / `\(...\)` / `\[...\]` 时才会加载 MathJax |
| 图表 | 用 `hexo-filter-mermaid-diagrams`,接近视口才渲染 |
| 隐藏内容 | 隐藏块里的内容仍会出现在 HTML 中(前端展开),**不要放真正的隐私信息** |
